## 🌟 Tính Năng Nổi Bật

- **📖 Thư Viện Bài Hát & Trình Xem Hợp Âm Chuyên Nghiệp:**
  - Định dạng hiển thị hợp âm trực quan trên lời bài hát.
  - Tự động căn chỉnh & **chia đều cột linh hoạt (1C - 2C - 3C - 4C)** không lo đứt dòng.
  - Tăng/giảm Tone (Transpose) chỉ với 1 click.
  - Tùy chỉnh cỡ chữ, phông chữ (Serif, Sans, Mono) phù hợp mắt nhìn trên sân khấu.
  - Tra cứu thế bấm hợp âm Guitar trực quan.

- **⚡ Tích Hợp Tìm Kiếm & Tải Bài Tự Động Từ Hợp Âm Chuẩn:**
  - Nhập tên bài hát hoặc dán link Hợp Âm Chuẩn để tự động tải lời & hợp âm chuẩn xác chỉ trong 2 giây.

- **🎤 Chế Độ Sân Khấu (Stage Mode):**
  - Giao diện Dark mode tối ưu hóa ánh sáng sân khấu, chống chói mắt.
  - **Tự động cuộn trang (Auto-scroll)** với điều chỉnh tốc độ mượt mà.
  - **Máy đếm nhịp (Metronome)** tích hợp âm thanh & nhịp đập trực quan.
  - **Screen Wake Lock**: Giữ màn hình luôn sáng, không bị khóa màn hình khi đang biểu diễn.

- **📋 Quản Lý Setlist Đêm Nhạc:**
  - Tạo danh sách bài hát cho từng buổi biểu diễn.
  - Sắp xếp thứ tự, ghi chú ca sĩ hát, tone bài hát, nhịp điệu.

- **📲 Kết Nối Mọi Thiết Bị Trong Ban Nhạc (Mã QR & LAN):**
  - Mở hợp âm tức thì trên điện thoại, iPad, máy tính bảng của tất cả thành viên trong band.
  - Quét **Mã QR** nhanh chóng không cần gõ bàn phím.
  - Hỗ trợ chuẩn **PWA (Progressive Web App)**: Cài đặt trực tiếp ra màn hình chính, mở toàn màn hình không có thanh địa chỉ duyệt web.

## 🚀 Khởi Chạy Dự Án Cục Bộ (Local)

1. **Cài đặt thư viện:**
   ```bash
   npm install
   ```

2. **Chạy máy chủ phát triển:**
   ```bash
   npm run dev
   ```

3. Mở trình duyệt và truy cập: [http://localhost:3000](http://localhost:3000) hoặc địa chỉ IP mạng nội bộ để các thiết bị khác cùng truy cập.
